# Plugin Community Reading Space (SLiMS)

Plugin tambahan untuk Senayan Library Management System (SLiMS).

## Cara Instalasi
1. Klik tombol **Code** > **Download ZIP**, lalu ekstrak file.
2. Salin folder `community_reading_space` ke dalam direktori `plugins/` pada instalasi SLiMS.
3. Login ke Admin SLiMS, lalu buka menu **Sistem** > **Plugin**.
4. Cari **Community Reading Space** dan klik **Aktifkan (Enable)**.
